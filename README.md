# 泰拉终端（MaiPRTS）— 明日方舟 PRTS Wiki 插件

面向 **MaiBot（麦麦）** 的轻量级《明日方舟》PRTS Wiki 知识与立绘插件：在聊天中自动听懂群友的方舟干员外号与社区黑话，按需精准查询干员技能、专属模组、升级/专精材料、干员档案与剧情词条，并支持在群聊/私聊中即时发送干员精二、初始与皮肤高清立绘。

---

## 核心设计特点

- **微秒级黑话语境感知（零污染记忆库）**：通过 `maisaka.planner.before_request` 在消息尾部追加 ≤180 字一次性参考小抄，既保持大模型前缀缓存（Prompt Prefix Caching）命中率，也不向麦麦核心数据库 `MaiBot.db` 或 `A_memorix` 记忆库写入任何游戏数据。
- **双档置信度防误触门控**：区分高置信专属词（如 `维什戴尔`、`水陈`、`罗德岛`、`精二`）与日常多义词（如 `叔叔`、`小羊`、`山`、`42`、`ew`），日常闲聊零误触，方舟群聊秒接梗。
- **高内聚双可见工具（`visibility="visible"`）**：
  - `ak_wiki_query`：单工具覆盖 `overview`（总览）/ `skills`（技能专三）/ `modules`（专属模组与升级材料）/ `materials`（精英化与专精材料）/ `lore`（干员档案与故事）/ `wiki`（任意剧情/活动/敌人/术语）。
  - `ak_send_illustration`：支持按外号、精二、初始、皮肤编号或皮肤中文名即时发送 1280px 清晰缩略图。
- **极致轻量与零额外重依赖**：仅依赖 MaiBot 环境自带的 `httpx` 与 Python 标准库 `sqlite3`，无需浏览器、无需独立后端进程、无需下载数百 MB 游戏包。
- **合规礼貌访问 PRTS**：规范 `User-Agent`、全局并发锁（最大并发 2）、请求最小间隔 ≥ 500ms、`429/503` 自动熔断退避，配合本地 SQLite 7 天文本缓存与 200MB 立绘 LRU 磁盘缓存。

## 快捷指令（可选）

除了在日常聊天中由麦麦自主理解与调用工具外，也提供不经 LLM 的直出指令：

- `/方舟 <干员/外号/词条> [总览|技能|模组|材料|档案]`（别名：`/prts`、`/ark`）
- `/立绘 <干员/外号> [精二|初始|皮肤1|皮肤名|列表]`（别名：`/方舟立绘`、`/ak图`）

示例：
- `/方舟 ew 模组`
- `/方舟 42 材料`
- `/立绘 水陈 列表`
- `/立绘 维什戴尔 超新星`

---

## 安装与配置

1. 将本插件目录放入 MaiBot 实例的 `plugins/` 目录下（如 `plugins/arknights_wiki/`）。
2. 启动或重载 MaiBot，宿主将按 `config_schema` 自动生成运行时配置；完整配置说明可参考 [config.example.toml](./config.example.toml)。
3. 可在 `[glossary].custom_aliases` 中随时追加自定义群内别称，格式为 `"外号=标准PRTS词条名|简短定位"`。
