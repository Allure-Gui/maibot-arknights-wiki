# 明日方舟wiki插件

给 **MaiBot（麦麦）** 用的《明日方舟》PRTS Wiki 查询与立绘插件。群里聊方舟时能听懂干员外号和社区黑话，也能随时查技能、模组、养成材料、干员档案和发高清精二/皮肤立绘。

---

## 主要功能

- **日常聊天听懂黑话（不乱刷屏、不污染记忆）**：在群友提到干员名或黑话时，给麦麦附带一小段临时参考（最多 180 字），不往 `MaiBot.db` 写游戏资料，也不破坏提示词缓存。区分专属词（像 `维什戴尔`、`水陈`、`精二`）和日常多义词（像 `叔叔`、`小羊`、`山`、`42`、`ew`），平时闲聊不会误触发。
- **2x 高清工业风卡片图**：查干员总览、技能专三、专属模组或精二/专精材料时，会用宿主自带的 `render.html2png` 拼一张带真实 PRTS 材料图标的高清卡片发出来；发完图默认直接收工，不跟着蹦多余废话（平台不支持发图时自动退回纯文本）。
- **高清立绘直发**：支持按外号、精二、初始、皮肤编号或皮肤中文名发图（默认 1600px，原图 ≤3.5MB 直接发无损原图）。
- **轻量、按需缓存**：只用到 MaiBot 自带的 `httpx` 和标准库 `sqlite3`，不用装额外重依赖，也不用提前下几百 MB 游戏包。请求 PRTS 带规范 UA、并发限流（最多 2 并发、间隔 ≥500ms）和 429 自动退避，缓存统一存在插件数据目录（`data/plugins/feiyu.arknights-wiki/`），7 天文本缓存 + 200MB 立绘 LRU 自动淘汰。

## 快捷指令

除了聊天里让麦麦自己判断调工具，也可以直接用斜杠指令直出（不走大模型，直接回）：

- `/方舟 <干员/外号/词条> [总览|技能|模组|材料|档案]`（别名 `/prts`、`/ark`）
- `/立绘 <干员/外号> [精二|初始|皮肤1|皮肤名|列表]`（别名 `/方舟立绘`、`/ak图`）
- `/方舟 缓存`：看当前本地缓存占了多少
- `/方舟 清理缓存`：清空本地词条和图片缓存（群聊里仅管理员可用）

几个顺手的例子：
- `/方舟 ew 模组`
- `/方舟 叔叔 材料`
- `/立绘 水陈 列表`
- `/立绘 维什戴尔 超新星`

## 安装与配置

1. 从 [Releases](https://github.com/Allure-Gui/maibot-arknights-wiki/releases) 下载源码包解压到 MaiBot 的 `plugins/` 目录（文件夹名比如 `arknights_wiki`），或者直接 `git clone` 进去。
2. 启动或重载 MaiBot，插件设置页会自动生成配置项，完整字段可以参考 [`config.example.toml`](./config.example.toml)。
3. 常用配置：
   - `[scope]`：按群号/用户 ID 配置黑白名单（留空默认全开）；
   - `[commands].admin_users`：填允许在群里执行 `/方舟 清理缓存` 的管理员 ID（留空时会自动读宿主 `master_users`，都没填的话只允许私聊清理）；
   - `[glossary].custom_aliases`：可以自己追加群里常用的外号，格式 `"外号=标准PRTS词条名|简短定位"`。
