# 明日方舟wiki插件

给 **MaiBot（麦麦）** 用的《明日方舟》PRTS Wiki 查询与实用工具插件。群里聊方舟时能听懂干员外号和自定义黑话，随时查技能、模组、材料总账、当期活动、公招保底、干员台词，也能直接发 2x 高清「黑曜石与金箔」风格卡片图和精二/皮肤立绘。

---

## 能干嘛

- **黑话语境感知 + 自定义昵称**：群友聊方舟时在消息尾部塞一小段临时参考（≤180 字），不往 `MaiBot.db` 写游戏资料，也不破坏提示词缓存。内置双档防误触门控（平时聊“叔叔”“小羊”“山”不会误触），支持在插件设置页里直接填自定义黑话（`外号=干员名`、`外号:干员名`、`外号 干员名` 都认），也可以由管理员在群里用 `/方舟 别名 添加` 随时热加。
- **2x 高清卡片图 & 总帮助图**：查干员总览、技能、模组、材料会自动渲染带 PRTS 真实材料图标的高清卡片；发 `/方舟帮助` 直接出一张轻量总指令速查图，群友一眼看懂全部用法。发完图默认直接收工，不跟着蹦多余文字。
- **实用轻量小工具（零重依赖、几乎不占空间）**：
  - **养成材料总账**：`/方舟 总计 <干员> [精二|一二三技能|模组]` 一键合并算出总共要多少龙门币和各类素材。
  - **公开招募计算器**：`/公招 <词条1> <词条2> ...` 毫秒级算必出 4★ / 5★ / 6★ / 支援机械组合（自动从 PRTS 同步最新公招池，缓存仅 ~15 KB，支持 `高资`/`资深`/`机械`/`高台`/`地面` 等简写）。
  - **当期活动 & 卡池速查**：`/方舟 活动` 一句话列出国服当前正在开的活动、卡池和剩余时间（缓存 6 小时，~2 KB）。
  - **干员台词彩蛋**：`/方舟 语音 <干员> [戳一戳|信赖|交谈|随机]` 查中文语音台词（只存文本不存音频）。
  - **高清立绘直发**：`/立绘 <干员/外号> [精二|初始|皮肤1|皮肤名|列表]`，默认 1600px 且原图 ≤3.5MB 直出无损原图。
- **黑白名单与多平台输出**：群聊/私聊开关及黑白名单覆盖 Hook、Tool 和指令。Telegram 支持父群或具体话题名单，发送沿用当前会话路由。QQ 官方消息带适配器标记时启用去链接策略。ClawBot 可尝试发送单聊图片，图片失败时降级为文本。本地控制台使用文本。Discord 和其他 OneBot 实现的实际发送能力取决于所装适配器。

## 快捷指令一览

- `/方舟帮助`：发送全部指令的轻量速查卡片图（发 `/方舟` 或 `/方舟 帮助` 也可以）
- `/方舟 <干员/外号/词条> [总览|技能|模组|材料|档案]`（别名 `/prts`、`/ark`）
- `/方舟 总计 <干员> [精二|一二三技能|模组]`：一键汇总养成材料总账
- `/立绘 <干员/外号> [精二|初始|皮肤1|皮肤名|列表]`（别名 `/方舟立绘`、`/ak图`）
- `/公招 <词条1> <词条2> ...`（或 `/方舟 公招 ...`）：公开招募保底计算器
- `/方舟 活动`：查看国服当期活动与寻访卡池
- `/方舟 语音 <干员> [戳一戳|信赖|交谈|随机]`：查看干员中文台词
- `/方舟 别名 [列表|添加 外号 干员|删除 外号]`：查看或热维护自定义黑话（增删限管理员）
- `/方舟 缓存` / `/方舟 清理缓存`：查看或清空本地缓存（群聊清理限管理员）

## 安装与配置

1. 在麦麦插件市场搜索「明日方舟wiki插件」，选择市场提供的兼容版本。手动安装可从 [GitHub Releases](https://github.com/Allure-Gui/maibot-arknights-wiki/releases) 下载对应标签的源码包，解压到 MaiBot 的 `plugins/arknights_wiki/`，确认 `_manifest.json` 与 `plugin.py` 位于该目录根部。
2. 本版在 MaiBot `1.4.6`、`1.4.8` 和 Plugin SDK `2.23.0` 上做过离线回归。启动或重载 MaiBot 后，在插件设置页按需调整（完整样例见 [`config.example.toml`](./config.example.toml)）：
   - **生效范围与黑白名单**：自由开关群聊/私聊，并选「不限制 / 仅白名单 / 排除黑名单」；
   - **自定义黑话与昵称**：在 `[glossary].custom_aliases` 里按行填 `外号=干员名` 即可优先匹配；
   - **管理员**：在 `[commands].admin_users` 填管理员 ID，可写作 `platform:用户ID`。留空时读取宿主 `plugin.permission`，保留旧配置键回退。均未配置时，仅在明确识别为私聊且有用户 ID 的会话中允许清理缓存与增删黑话。
